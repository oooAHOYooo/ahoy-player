AHOY PLAYER · MAC INSTALL

Welcome aboard.

Your music stays on your Mac. Follow these steps to install the local player.

  1. Drag Ahoy Player.app onto the Applications folder.
  2. Eject this disk image from Finder after the copy finishes.
  3. Open Applications, then Control-click Ahoy Player and choose Open.
  4. If macOS asks for confirmation, choose Open again. This is a private test build.
Security note
Ahoy is currently distributed as a test build while Apple Developer signing and notarization are being completed. Never install a copy from an unknown source.
